# rns-page-node

rns-page-node は、Micron ページとファイルのディレクトリを [Reticulum](https://reticulum.network) ネットワーク上の宛先に変換します。これは [NomadNet](https://github.com/markqvist/NomadNet) のようなクライアントからのページ、ファイル、メディアのリクエストに応答します。
