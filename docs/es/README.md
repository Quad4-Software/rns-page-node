# rns-page-node

rns-page-node convierte un directorio de páginas Micron y archivos en un destino en la red [Reticulum](https://reticulum.network). Responde a solicitudes de páginas, archivos y medios desde clientes como [NomadNet](https://github.com/markqvist/NomadNet).
