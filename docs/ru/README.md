# rns-page-node

rns-page-node превращает каталог страниц Micron и файлов в назначение в сети [Reticulum](https://reticulum.network). Он отвечает на запросы страниц, файлов и медиа от клиентов, таких как [NomadNet](https://github.com/markqvist/NomadNet).
