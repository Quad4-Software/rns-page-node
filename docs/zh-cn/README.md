# rns-page-node

rns-page-node 将 Micron 页面和文件目录转换为 [Reticulum](https://reticulum.network) 网络上的一个目标节点。它响应来自 [NomadNet](https://github.com/markqvist/NomadNet) 等客户端的页面、文件和媒体请求。
