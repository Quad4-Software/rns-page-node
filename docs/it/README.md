# rns-page-node

rns-page-node trasforma una directory di pagine Micron e file in una destinazione sulla rete [Reticulum](https://reticulum.network). Risponde a richieste di pagine, file e media da client come [NomadNet](https://github.com/markqvist/NomadNet).
