# rns-page-node

rns-page-node verwandelt ein Verzeichnis mit Micron-Seiten und Dateien in ein Ziel im [Reticulum](https://reticulum.network)-Netzwerk. Es beantwortet Seiten-, Datei- und Medienanfragen von Clients wie [NomadNet](https://github.com/markqvist/NomadNet).
