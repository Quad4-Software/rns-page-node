# rns-page-node

rns-page-node transforme un répertoire de pages Micron et de fichiers en une destination sur le réseau [Reticulum](https://reticulum.network). Il répond aux requêtes de pages, de fichiers et de médias provenant de clients comme [NomadNet](https://github.com/markqvist/NomadNet).
